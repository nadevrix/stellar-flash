# Fotos de objeto (opcional)

Deja aquí PNG con fondo recortado y se usarán automáticamente:

| Archivo | Dónde sale | Qué representa |
|---|---|---|
| `ticket.png` | sección "The problem" | la espera, el "procesando…" |
| `telegraph.png` | sección "How it works" | transmisión instantánea |
| `stopwatch.png` | sección "Live" | los milisegundos |

Estilo: objeto fotográfico en blanco y negro de alto contraste, recortado, que se
apoya sobre un círculo dorado plano (el círculo lo pone el componente, la imagen
debe llevar fondo transparente). Cuadradas, 1200×1200 o más.

Si un archivo no existe, `ObjectShot` dibuja una versión en línea del objeto, así
que la página nunca se ve rota. No hace falta subirlos para desplegar.
